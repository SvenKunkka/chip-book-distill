# 芯片通识课 · 读书蒸馏页

《芯片通识课：一本书读懂芯片技术》（赵秋奇）的**读书蒸馏页** —— 一个零依赖、单文件的交互式 HTML，用浏览器直接打开即可阅读。

## 在线预览

开启 GitHub Pages 后访问：

```
https://svenkunkka.github.io/chip-book-distill/
```

## 本地阅读

```bash
git clone https://github.com/SvenKunkka/chip-book-distill.git
open chip-book-distill/index.html
```

页面完全自包含：没有外部 CSS / JS / 字体 / CDN 依赖，所有插图均为内联 SVG，离线可用。
文中的外部链接仅作为引用出处（豆瓣、EET-China、界面新闻等），不加载任何远程资源。

## 页面结构

按读者逻辑链组织的五个板块：

| 板块 | 内容 |
| --- | --- |
| 全书速览 `panel-glance` | 餐巾纸四件套（公式 / 读法 / 一句话）、因果骨架草图、脑图、核心观点卡、两种养法对照 |
| 逐章精读 `panel-full` | 概念筹码条、章节目录、手风琴式逐章精读、金句墙 |
| 批判与评价 `panel-judge` | 裁决条、立论复述、内在张力、批判四区、书评、观点对照 |
| 行动清单 `panel-action` | 五环路线图（含回环）、情境决策卡、模型抽屉卡、自检问题 |
| 延伸阅读 `panel-extend` | 同类书、阅读路径、作者书架、跨域命名、跨书回声、离开前带走 |
